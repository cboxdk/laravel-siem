# Cookbook

- [Stream to Splunk](stream-to-splunk.md) — HEC token, collector endpoint, NDJSON.
- [Stream to Elastic](stream-to-elastic.md) — ECS documents over HTTP with a
  bearer token.
- [Stream to Datadog](stream-to-datadog.md) — Logs API v2, API key, site, limits.
- [Stream to Amazon S3](stream-to-s3.md) — NDJSON objects, least-privilege IAM,
  access keys or an assumed role, SSE, MinIO/R2.
- [Stream to Google Cloud Storage](stream-to-gcs.md) — NDJSON objects, a
  service-account key with `roles/storage.objectCreator`.
